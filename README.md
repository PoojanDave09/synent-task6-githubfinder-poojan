# GitHub Profile Finder

A modern GitHub Profile Finder application built using HTML, CSS, and Vanilla JavaScript.

This application allows users to search for GitHub profiles and view detailed account information using the GitHub REST API.

---

## Features

### Core Features

- Search GitHub users
- Fetch real-time GitHub data
- Display profile details
- Responsive UI
- Dynamic rendering

### Profile Information

- Profile Picture
- Full Name
- Username
- Bio
- Followers Count
- Following Count
- Public Repositories
- Location
- Join Date
- GitHub Profile Link

### Advanced Features

- Loading Spinner
- Loading Messages
- Search History (Last 5 Searches)
- Clear History
- Enter Key Support
- Copy Profile URL
- Current Date & Time
- Auto Focus Search Field
- Smooth Animations
- Error Handling

### Error Handling

- Empty Username
- User Not Found
- API Failure
- Network Errors

## Installation Steps

### Clone Repository

```bash

```

Simply open:

```text
index.html
```

in your browser.

## GitHub API Used

```text
https://api.github.com/users/{username}
```

Example:

```text
https://api.github.com/users/octocat
```
